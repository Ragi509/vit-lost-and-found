# VIT Lost & Found - Web Application

Next.js 14 web application for the VIT Pune AI-assisted Lost and Found platform.

## Features
- Supabase Auth with custom 6-digit OTP verification & Resend delivery.
- Lost and Found item reporting with multi-image photo uploads.
- Automated AI multimodal matching and instant candidate retrieval.
- Comprehensive claim verification and item handover workflows.
- Real-time campus loss hotspots and recovery analytics dashboard.
